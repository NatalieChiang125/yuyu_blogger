# Family Food Blog (食帳網站)

一個個人開發的食帳網站，紀錄餐廳體驗與美食心得，支援多層分類、封面與內容圖片上傳，以及 Instagram 連結分享。  
網站以 **Next.js + TypeScript + Supabase** 建置。

---

## 功能 Features

- **文章管理**
  - 新增 / 編輯 / 刪除食帳文章
  - 每篇文章可設定：
    - 標題、ID
    - 封面圖片
    - 評分與價格
    - Instagram 連結
    - 三層分類（國家 → 地區 → 類型）
    - 內容區塊（文字或圖片 + 說明）
- **前端展示**
  - 首頁列表顯示所有文章
  - 支援圖片顯示與文字排版

---

## 技術棧 Tech Stack

- **前端**: Next.js (App Router / TypeScript / TailwindCSS)
- **後端 & DB**: Supabase (PostgreSQL + Storage)
- **部署**: Vercel
